# Collaborative Stock Watchlist Platform

A full-stack web application that allows users to track real-time stock prices, manage personalized watchlists, and share them with friends.

## 🚀 Features
- User authentication (Register / Login)
- Personalized stock watchlists
- Real-time stock price updates (every minute)
- Secure API integration with stock APIs
- Share watchlists with friends (read-only access)
- User-specific dashboard

## 🛠 Tech Stack
Frontend: React  
Backend: Django, Django REST Framework  
Database: PostgreSQL  
Background Jobs: Celery + Redis  
Stock API: Finnhub
